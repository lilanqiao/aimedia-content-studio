# 改文工坊 · 提示词自动填充插件 — 安装

装一次,以后从分镜页点「打开 ChatGPT/Grok/Gemini 出图/出视频」,提示词会**自动填进网页输入框**(不自动发送,你看一眼再回车)。

## 安装步骤(一次性,约 1 分钟)

1. Chrome 地址栏输入:`chrome://extensions`,回车
2. 打开右上角的 **「开发者模式」** 开关
3. 点左上角 **「加载已解压的扩展程序」**
4. 选这个文件夹:本工坊目录下的 `extension`
5. 装好后列表里出现「提示词自动填充」即可

## 怎么用
- 在分镜页正常点按钮 → 它打开网页 + 自动把提示词填进输入框
- 你检查一下,**自己按回车发送**(插件不自动发,安全)
- 没装插件也不影响:提示词同时复制到了剪贴板,你手动 Cmd+V 粘贴即可

## 说明 / 限制
- 只在 chatgpt.com / grok.com / gemini.google.com 这几个站生效,不碰别的网页。
- 出图后的图、出视频的素材,仍需你手动下载/在 Grok 拖图(浏览器不允许网站间自动传图片文件)。
- 如果哪天这些网站改版,自动填可能失灵,告诉我我更新 content.js 里的输入框选择器。
